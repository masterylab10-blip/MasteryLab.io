🎓 Teachers Education Led by Christina & Rebeca

A structured 3-level certification program for current and aspiring instructors.

All participants must complete all three levels to finish the full program and receive certification.

  • If you start with Perfect Start → you continue with Almost There, then I Made It
  • If you start with Almost There → you must also complete Perfect Start and I Made It
  • If you start with I Made It → you must also complete Perfect Start and Almost There

Each level must be completed to receive the full program certification.
